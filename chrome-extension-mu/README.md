# Mafia Host → MafiaUniverse Importer

Chrome-расширение, которое подставляет итоги игры из приложения Mafia Host
в форму редактирования игры на `mafiauniverse.org/Games/Edit`.

## Установка (Developer mode)

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите тумблер **Developer mode** (правый верхний угол).
3. Нажмите **Load unpacked** и укажите эту папку (`chrome-extension-mu`).
4. В списке расширений появится «Mafia Host → MafiaUniverse Importer».
   Закрепите иконку в панели расширений (значок-пазл → булавка).

## Использование

1. В приложении Mafia Host откройте итоговый экран и нажмите
   **Скопировать MU JSON** — JSON попадёт в буфер.
2. На сайте MafiaUniverse откройте страницу создания/редактирования игры:
   `https://mafiauniverse.org/Games/Edit?...` (через кнопку «Новая игра» в турнире/клубе).
3. Кликните по иконке расширения, нажмите **Вставить** (или вставьте JSON вручную
   в textarea), затем **Заполнить форму**.
4. Проверьте всё глазами: роли, фолы, доп. баллы, голосования.
   Привяжите ники к игрокам в базе MU через выпадающий список рядом
   с каждым именем (расширение оставляет их как «Гость» — это поведение по умолчанию MU).
5. Сохраните игру кнопкой сайта.

## Что подставляется

- Дата игры (`DateOfGame`)
- Ведущий (текстом, без привязки к БД)
- Победитель (`GameWinnerId`)
- Коэффициент игры (`ScoreCoefficient`)
- Для каждой из 10 позиций:
  - Никнейм текстом (`PlayerName_i`, `NickName`)
  - Роль (`GameRoleId`: 1=Мирный, 2=Шериф, 3=Мафия, 4=Дон)
  - Фолы (`Foul`, hidden)
  - Первый отстрел (`KilledFirst`, hidden)
  - Лучший ход (`BestMove`)
  - Доп. баллы плюс / минус (`BonusScore`, `PenaltyScore`)
  - Технический штраф (`TechPenaltyScore`)
- Голосования — пишутся в скрытое поле `Process`
  как массив `[{VotingId, VotingStrings:[{PlayerNumber, VotesCount}]}]`,
  а также рендерятся в превью-таблицу «Результаты голосований» внизу страницы
  (строки помечаются `data-mu-importer="1"`, чтобы не конфликтовать с тем,
  что нарисовал сайт сам). На сервер уходит содержимое `Process`.

## Известные ограничения

- **Привязка к БД игроков** — никнеймы вставляются текстом, как «Гость».
  В одном клубе нередко несколько игроков с одинаковыми никами из разных клубов,
  поэтому выбор «настоящего» игрока в БД оставлен ручным.
- **Фолы и «первый убитый» не отрисовываются** —
  значения сидят в скрытых input-ах. После сохранения и перезагрузки страницы
  всё отобразится корректно.
- **Превью голосований ≠ внутренний state сайта.** Превью отрисовывается
  поверх таблицы `#Votings`, но виджет «Текущее голосование» (`#TableOfCurrentVoting`)
  при этом не наполняется — он показывает только активную сессию голосования.
  Если потребуется, чтобы виджет тоже наполнялся, можно вызывать `AddPlayerToVote`
  из page-world через `chrome.scripting.executeScript({ world: 'MAIN' })`.
- **Не поддерживается ничья** — наше приложение не различает ничью отдельно;
  в JSON значение `winner` будет `null`, и поле «Победа» останется пустым.

## Структура JSON

```json
{
  "version": 1,
  "source": "mafia-host-app",
  "dateOfGame": "14-05-2026 15:58",
  "host": "Имя Ведущего",
  "winner": "peaceful",
  "scoreCoefficient": "1.0",
  "players": [
    {
      "position": 1,
      "nick": "Игрок",
      "roleId": 3,
      "fouls": 1,
      "killedFirst": false,
      "bestMove": "2,5,8",
      "bonusPlus": "0,50",
      "bonusMinus": "0,00",
      "techMinus": "0,00"
    }
  ],
  "votings": [
    { "candidates": [{ "playerNumber": 1, "votesCount": 5 }] }
  ]
}
```
